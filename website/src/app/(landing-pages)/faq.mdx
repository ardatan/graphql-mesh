## Frequently Asked Questions

- What is GraphQL Mesh?

  A **Federation Framework for any API**. It turns GraphQL and non-GraphQL sources into
  Federation-ready subgraphs. Platform / registry / gateway independent.
  [Mesh v2 introduction](/v2).

- Already have Federation: why Mesh?

  Non-GraphQL sources as Federation subgraphs, transforms, drop into Router / Hive without replacing
  the stack. [FAQ](/v2/faq#already-have-federation-why-mesh).

- New to Federation: why Mesh?

  Generate Federation-ready subgraphs from OpenAPI / SQL / etc., then compose and serve on any
  Federation gateway. [FAQ](/v2/faq#new-to-federation-why-mesh).

- How do I go from a source to a running graph?

  Generate → optional Transform → Serve Subgraph when needed → Compose → Gateway.
  [Build your Subgraph](/v2/paths/generate), [Serve Supergraph](/v2/serve), [FAQ](/v2/faq).

- Can Mesh enhance an existing Federation setup?

  Yes. Keep GraphOS / Router, Hive Gateway / Registry, or any Federation stack; add Mesh subgraphs.
  [Introduction](/v2#enhance-an-existing-federation) /
  [FAQ](/v2/faq#can-mesh-drop-into-an-existing-federation-setup).
