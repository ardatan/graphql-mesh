# SQLite

Use `@omnigraph/sql` with `type: 'sqlite'`. The loader introspects the database and emits GraphQL
SDL annotated with `@sql__query` / `@sql__mutation` / `@sql__relation`. Runtime is
`@graphql-mesh/transport-sql` (`kind: "sql"`).

```sh npm2yarn
npm i @omnigraph/sql
```

```ts filename="mesh.config.ts"
import { defineConfig } from '@graphql-mesh/compose-cli'
import { loadSqlSubgraph } from '@omnigraph/sql'

export const composeConfig = defineConfig({
  subgraphs: [
    {
      sourceHandler: loadSqlSubgraph('chinook', {
        type: 'sqlite',
        db: 'chinook.db'
      })
    }
  ]
})
```

<Callout type="info">
  This replaces the old `@omnigraph/sqlite` (tuql) and legacy `@graphql-mesh/tuql` handlers. Emit is
  Connectors-style `@sql__*` directives — not a black-box PostGraphile/tuql runtime schema.
</Callout>
