# Protocols

Each family has an optional loader, directive emit, transport, and honest Apollo Router dual-run
notes. Pick the page that matches **what the source is for** -- each one leads with concrete
excerpts and use cases, not an arg laundry list.

**HTTP/REST Connectors** (`@connect` / `@source`) are one family. Do **not** brand Mesh-only
protocols (SQL, Mongo, Protobuf, ...) as Connectors.

| Family                                      | When to open it                                  | Transport                            | Apollo Router dual-run   |
| ------------------------------------------- | ------------------------------------------------ | ------------------------------------ | ------------------------ |
| REST / OpenAPI / JSON Schema / RAML / OData | HTTP JSON APIs, entity lookups, FHIR             | `transport-connect`                  | Yes (Connect-compatible) |
| SOAP / WSDL                                 | WSDL ops as Connect + XML body                   | `transport-connect` (+ XML codec)    | No                       |
| SQL                                         | Tables, FKs, CRUD, Federation entity fill        | `transport-sql`                      | No (Hive Gateway)        |
| Mongo                                       | Collections, find/filter/CRUD, ObjectId entities | `transport-mongo`                    | No                       |
| Neo4j                                       | Nodes / relationships via Neo4j GraphQL natives  | `transport-neo4j`                    | No                       |
| Thrift                                      | `.thrift` IDL -- binary RPC or TJSON Connect     | `transport-thrift` / Connect (TJSON) | TJSON `@connect` only    |
| Protobuf / gRPC                             | RPC field-number maps (`@protobuf__rpc`)         | `transport-protobuf`                 | No                       |
| GraphQL HTTP / Federation                   | Existing GraphQL / Federation subgraphs          | `http` / federation                  | N/A                      |

Shared skills: [Selection mapping](/v2/guides/selection-mapping),
[Entity resolution](/v2/concepts/federation#entity-resolution),
[Directives](/v2/reference/directives).
