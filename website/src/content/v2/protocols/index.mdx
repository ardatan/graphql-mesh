# Protocols

Protocol chapters expand here. Each family has a loader (optional), directive emit, transport, and
honest Router dual-run notes.

| Family                              | Transport                            | Apollo Router dual-run |
| ----------------------------------- | ------------------------------------ | ---------------------- |
| REST / OpenAPI / JSON Schema / RAML | `transport-connect`                  | Yes                    |
| OData                               | `transport-connect`                  | Yes                    |
| SOAP / WSDL                         | `transport-connect` (+ XML codec)    | No                     |
| SQL                                 | `transport-sql`                      | No (Hive Gateway)      |
| Mongo                               | `transport-mongo`                    | No                     |
| Neo4j                               | `transport-neo4j`                    | No                     |
| Thrift                              | `transport-thrift` / connect (TJSON) | TJSON `@connect` only  |
| Protobuf / gRPC                     | `transport-protobuf`                 | No                     |
| GraphQL HTTP / Federation           | `http` / federation                  | N/A                    |
