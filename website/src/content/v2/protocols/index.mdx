# Protocols

Each family has an optional loader, directive emit, transport, and honest Apollo Router dual-run
notes. **HTTP/REST Connectors** (`@connect` / `@source`) are one family -- do not brand Mesh-only
protocols (SQL, Mongo, Protobuf, ...) as Connectors.

| Family                                      | Page                                      | Transport                            | Apollo Router dual-run   |
| ------------------------------------------- | ----------------------------------------- | ------------------------------------ | ------------------------ |
| REST / OpenAPI / JSON Schema / RAML / OData | [HTTP / REST](/v2/protocols/http-rest)    | `transport-connect`                  | Yes (Connect-compatible) |
| SOAP / WSDL                                 | [HTTP / REST](/v2/protocols/http-rest)    | `transport-connect` (+ XML codec)    | No                       |
| SQL                                         | [SQL](/v2/protocols/sql)                  | `transport-sql`                      | No (Hive Gateway)        |
| Mongo                                       | [Mongo](/v2/protocols/mongo)              | `transport-mongo`                    | No                       |
| Neo4j                                       | [Neo4j](/v2/protocols/neo4j)              | `transport-neo4j`                    | No                       |
| Thrift                                      | [Thrift](/v2/protocols/thrift)            | `transport-thrift` / Connect (TJSON) | TJSON `@connect` only    |
| Protobuf / gRPC                             | [Protobuf / gRPC](/v2/protocols/protobuf) | `transport-protobuf`                 | No                       |
| GraphQL HTTP / Federation                   | --                                        | `http` / federation                  | N/A                      |

Shared skills: [Selection mapping](/v2/guides/selection-mapping),
[Entity resolution](/v2/concepts/federation#entity-resolution),
[Directives](/v2/reference/directives).
