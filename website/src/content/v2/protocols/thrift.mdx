# Thrift

Thrift has two Mesh paths. Anchor: `e2e/thrift-calculator` (`.thrift` IDL + binary compose vs JSON
compose).

| Path            | Directives                                               | Dual-run                              |
| --------------- | -------------------------------------------------------- | ------------------------------------- |
| Binary Thrift   | <DirectiveRef name="thrift__rpc" /> + `transport-thrift` | Hive Gateway only                     |
| TJSON over HTTP | May emit HTTP/REST Connectors `@connect`                 | Apollo Router when Connect-compatible |

## Generate (binary)

`loadThriftSubgraph` with `protocol: 'binary'` emits `@thrift__rpc` + thrift `@transport`:

```ts
import { defineConfig } from '@graphql-mesh/compose-cli'
import { loadThriftSubgraph } from '@omnigraph/thrift'

export const composeConfig = defineConfig({
  subgraphs: [
    {
      sourceHandler: loadThriftSubgraph('calculator', {
        source: './services/calculator/calculator.thrift',
        endpoint: 'http://localhost:4001/thrift',
        serviceName: 'Calculator',
        protocol: 'binary'
      })
    }
  ]
})
```

Compact hand / emitted shape (same idea as the loader docstring and composition tests):

```graphql
extend schema
  @link(url: "https://specs.graphql-mesh.com/thrift/v0.1", import: ["@thrift__rpc"])
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])

type Query {
  add(request: AddRequestInput): Int
    @thrift__rpc(
      function: "add"
      args: """
      1(struct): $args.request {
        1(i32): left
        2(i32): right
      }
      """
      selection: "$(i32)"
      messageType: CALL
    )
}
```

`args` / `selection` / `throws` use Thrift wire types (`i32`, `struct`, ...) instead of Protobuf
field numbers. See [Selection mapping](/v2/guides/selection-mapping) and
[Directives](/v2/reference/directives#thrift).

## Generate (TJSON)

Same IDL, `protocol: 'json'` -- emit switches to HTTP/REST Connectors `@source` + `@connect` (Hive
Gateway and, when Connect-compatible, Apollo Router). Do **not** call binary Thrift "Connectors";
only the TJSON path shares that contract.

```ts
loadThriftSubgraph('calculator', {
  source: './services/calculator/calculator.thrift',
  endpoint: 'http://localhost:4001/thrift-json',
  protocol: 'json'
})
```
