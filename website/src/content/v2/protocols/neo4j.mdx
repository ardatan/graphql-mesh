# Neo4j

Use Neo4j when the graph already lives in **Bolt / Cypher** and you want GraphQL types that mirror
nodes and relationships (filters, sorts, relationship properties). Mesh does **not** invent a
`@neo4j__*` dialect: it stamps <DirectiveRef name="transport" /> + a neo4j `@link`, and reuses
**native** `@neo4j/graphql` directives (`@node`, `@relationship`, ...). Not HTTP/REST Connectors.
Hive Gateway only.

| Piece      | Detail                                                  |
| ---------- | ------------------------------------------------------- |
| Loader     | `@omnigraph/neo4j` (introspect or accept author SDL)    |
| Directives | Native `@neo4j/graphql` (`@node`, `@relationship`, ...) |
| Transport  | `@graphql-mesh/transport-neo4j`                         |
| Spec stamp | `https://specs.graphql-mesh.com/neo4j/v0.1`             |
| Dual-run   | Hive Gateway only                                       |
| Anchor     | `e2e/neo4j-example` (Movies dataset)                    |

## Generate

```ts
import { defineConfig } from '@graphql-mesh/compose-cli'
import { loadNeo4JSubgraph } from '@omnigraph/neo4j'

export const composeConfig = defineConfig({
  subgraphs: [
    {
      sourceHandler: loadNeo4JSubgraph('Movies', {
        endpoint: 'neo4j://localhost:7687',
        auth: {
          type: 'basic',
          username: 'neo4j',
          password: 'password'
        }
      })
    }
  ]
})
```

## What the emit looks like

Transport stamp + relationship graph (`e2e/neo4j-example`):

```graphql
extend schema
  @link(
    url: "https://specs.graphql-mesh.com/neo4j/v0.1"
    import: ["@node", "@relationship", "@relationshipProperties"]
  )
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])

schema @transport(subgraph: "Movies", kind: "neo4j", location: "neo4j://localhost:7687") {
  query: Query
}

type Movie @node {
  title: String
  peopleActedIn(where: PersonWhere, limit: Int, offset: Int): [Person!]!
    @relationship(type: "ACTED_IN", direction: IN, properties: "ActedInProperties")
  peopleDirected(where: PersonWhere, limit: Int, offset: Int): [Person!]!
    @relationship(type: "DIRECTED", direction: IN)
}

type Person @node {
  name: String
  actedInMovies(where: MovieWhere, limit: Int, offset: Int): [Movie!]!
    @relationship(type: "ACTED_IN", direction: OUT, properties: "ActedInProperties")
  directedMovies(where: MovieWhere, limit: Int, offset: Int): [Movie!]!
    @relationship(type: "DIRECTED", direction: OUT)
}

type ActedInProperties @relationshipProperties {
  roles: [String!]
}
```

Mesh's job is the transport + federation join; Cypher generation stays with Neo4j GraphQL. Catalog:
[Directives: Neo4j](/v2/reference/directives#neo4j). Serve: [Hive Gateway](/v2/serve/hive-gateway).
