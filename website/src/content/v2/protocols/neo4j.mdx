# Neo4j

Use Neo4j when the graph already lives in **Bolt** and you want GraphQL types that mirror nodes and
relationships. Mesh does **not** invent a `@neo4j__*` dialect. It stamps

<DirectiveRef name="transport" /> + a neo4j `@link`, and reuses **native** `@neo4j/graphql`
directives (`@node`, `@relationship`, `@relationshipProperties`). Cypher and schema mapping run
**under the hood via Neo4j GraphQL** -- Mesh's job is the transport + federation join. Not HTTP/REST
Connectors. Hive Gateway only.

| Piece      | Detail                                                  |
| ---------- | ------------------------------------------------------- |
| Loader     | `@omnigraph/neo4j` (introspect or accept author SDL)    |
| Directives | Native `@neo4j/graphql` (`@node`, `@relationship`, ...) |
| Transport  | `@graphql-mesh/transport-neo4j`                         |
| Spec stamp | `https://specs.graphql-mesh.com/neo4j/v0.1`             |
| Dual-run   | Hive Gateway only                                       |
| Anchor     | `e2e/neo4j-example` (Movies dataset)                    |

Upstream type definitions: [Relationships](https://neo4j.com/docs/graphql/current/relationships/) /
[Database mapping](https://neo4j.com/docs/graphql/current/directives/database-mapping/).

## Generate

```ts
import { defineConfig } from '@graphql-mesh/compose-cli'
import { loadNeo4JSubgraph } from '@omnigraph/neo4j'

export const composeConfig = defineConfig({
  subgraphs: [
    {
      sourceHandler: loadNeo4JSubgraph('Movies', {
        endpoint: 'neo4j://localhost:7687',
        auth: {
          type: 'basic',
          username: 'neo4j',
          password: 'password'
        }
      })
    }
  ]
})
```

## Type definitions (Neo4j GraphQL Movies)

Author or accept the same SDL Neo4j GraphQL documents for a `Person` / `Movie` graph with `ACTED_IN`
and edge `roles` (from Neo4j's
[Relationships](https://neo4j.com/docs/graphql/current/relationships/) guide):

```graphql
type ActedIn @relationshipProperties {
  roles: [String!]
}

type Person @node {
  name: String!
  actedIn: [Movie!]! @relationship(type: "ACTED_IN", properties: "ActedIn", direction: OUT)
}

type Movie @node {
  title: String!
  released: Int!
  actors: [Person!]! @relationship(type: "ACTED_IN", properties: "ActedIn", direction: IN)
}
```

- `@node` -- this GraphQL type is a Neo4j node (optional `labels` when the DB label differs).
- `@relationship` -- field is an edge (`type` + `direction`; optional `properties`).
- `@relationshipProperties` -- object that holds properties on that edge.

Mesh wraps the subgraph with its stamp so Hive Gateway loads `transport-neo4j`:

```graphql
extend schema
  @link(
    url: "https://specs.graphql-mesh.com/neo4j/v0.1"
    import: ["@node", "@relationship", "@relationshipProperties"]
  )
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])

schema @transport(subgraph: "Movies", kind: "neo4j", location: "neo4j://localhost:7687") {
  query: Query
}
```

## Complex Use Cases

### Introspected pluralization + both directions

Neo4j GraphQL pluralization names both ends of an edge (`actedInMovies` on `Person`, `peopleActedIn`
on `Movie`). Emit stamps `@relationship` on **both** directions of `ACTED_IN` / `DIRECTED` /
`REVIEWED` (IN on `Movie`, OUT on `Person`):

```graphql
type Person @node {
  name: String!
  # OUT: person acted in movies
  actedInMovies: [Movie!]!
    @relationship(type: "ACTED_IN", direction: OUT, properties: "ActedInProperties")
}

type Movie @node {
  title: String!
  # IN: people who acted in this movie (same ACTED_IN edge, other end)
  peopleActedIn: [Person!]!
    @relationship(type: "ACTED_IN", direction: IN, properties: "ActedInProperties")
}
```

### Relationship properties

Edges with properties get a `@relationshipProperties` type. `ACTED_IN` carries `roles`; the
`properties:` arg on `@relationship` points at that type:

```graphql
type ActedInProperties @relationshipProperties {
  roles: [String!] # edge property on ACTED_IN
}

type Person @node {
  name: String!
  actedInMovies: [Movie!]!
    @relationship(
      type: "ACTED_IN"
      direction: OUT
      properties: "ActedInProperties" # links to ActedInProperties above
    )
}
```

### Mesh `subgraph:` on natives

Compose may print `subgraph:` on Neo4j natives so transports filter by `@transport(subgraph:)`.
These are still Neo4j GraphQL directives, not a Mesh-only dialect:

```graphql
type Movie @node(subgraph: "Movies") {
  title: String!
  actors: [Person!]! @relationship(type: "ACTED_IN", direction: IN, subgraph: "Movies")
}

# Transport stamp matches the subgraph name on the natives
extend schema @transport(subgraph: "Movies", kind: "neo4j", location: "bolt://...")
```
