# Neo4j

Neo4j is a **Mesh protocol** that uses **native** `@neo4j/graphql` directives (not a Mesh
`@neo4j__*` dialect and not HTTP/REST Connectors). Mesh stamps <DirectiveRef name="transport" /> and
a neo4j `@link`; Cypher / filter mapping lives in Neo4j GraphQL itself. Anchor: `e2e/neo4j-example`.

| Piece      | Detail                                               |
| ---------- | ---------------------------------------------------- |
| Loader     | `@omnigraph/neo4j` (introspect or accept author SDL) |
| Directives | Native `@neo4j/graphql`                              |
| Transport  | `@graphql-mesh/transport-neo4j`                      |
| Spec stamp | `https://specs.graphql-mesh.com/neo4j/v0.1`          |
| Dual-run   | Hive Gateway only                                    |

## Generate

```ts
import { defineConfig } from '@graphql-mesh/compose-cli'
import { loadNeo4JSubgraph } from '@omnigraph/neo4j'

export const composeConfig = defineConfig({
  subgraphs: [
    {
      sourceHandler: loadNeo4JSubgraph('Movies', {
        endpoint: 'neo4j://localhost:7687',
        auth: {
          type: 'basic',
          username: 'neo4j',
          password: 'password'
        }
      })
    }
  ]
})
```

Emitted / hand stamp shape:

```graphql
extend schema
  @link(url: "https://specs.graphql-mesh.com/neo4j/v0.1")
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])

schema @transport(subgraph: "Movies", kind: "neo4j", location: "bolt://localhost:7687") {
  query: Query
}
```

Type and field mapping stay on Neo4j GraphQL natives (`@node`, `@relationship`, ...). Mesh only
marks the subgraph for `transport-neo4j`. See [Directives](/v2/reference/directives#neo4j).

Serve with [Hive Gateway](/v2/serve/hive-gateway) (stock Apollo Router does not run this transport).
