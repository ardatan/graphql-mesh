# HTTP / REST

Mesh maps HTTP APIs with <ConceptRef name="connectors">HTTP/REST Connectors</ConceptRef>
(<DirectiveRef name="connect" /> / <DirectiveRef name="source" />, connect/v0.4). Loaders for
OpenAPI, JSON Schema, OData, and SOAP-as-Connect **emit** that shape; authors can hand-write it.

| Piece     | Detail                                                                               |
| --------- | ------------------------------------------------------------------------------------ |
| Loaders   | `@omnigraph/openapi`, `@omnigraph/json-schema`, OData, SOAP                          |
| Transport | `@graphql-mesh/transport-connect` on Hive Gateway                                    |
| Dual-run  | Same Connect SDL on [Apollo Router](/v2/serve/apollo-router) when Connect-compatible |
| Spec      | `https://specs.apollo.dev/connect/v0.4`                                              |

## Loader -> Connect emit (entity lookup)

From `e2e/openapi-entity-stubs` (Billing OpenAPI). Composition stamps `entity: true` when the Query
arg matches the entity key ([ById conventions](/v2/compose#semantic-conventions)):

```ts
import { defineConfig as defineComposeConfig } from '@graphql-mesh/compose-cli'
import { loadOpenAPISubgraph } from '@omnigraph/openapi'

export const composeConfig = defineComposeConfig({
  subgraphs: [
    {
      sourceHandler: loadOpenAPISubgraph('Billing', {
        source: './openapi.yaml',
        endpoint: 'http://localhost:4001'
      })
    }
  ]
})
```

Emitted shape (simplified from the e2e snapshot):

```graphql
extend schema
  @link(url: "https://specs.apollo.dev/connect/v0.4", import: ["@connect", "@source"])
  @source(name: "Billing", http: { baseURL: "http://localhost:4001" })

type Query {
  getCustomer(id: String!): Customer
    @connect(
      source: "Billing"
      http: { GET: "/customers/{$args.id}" }
      selection: """
      id
      name
      """
      entity: true
    )
}
```

FHIR JSON Schema + join SDL: [FHIR](/v2/examples/fhir). Arg / selection dialect:
[Selection mapping](/v2/guides/selection-mapping). Upstream:
[Apollo's HTTP Connectors reference](https://www.apollographql.com/docs/graphos/connectors/reference/directives).
