# Mongo

Use Mongo when collections should become GraphQL types with **find / filter / aggregate / CRUD**
ops, ObjectId keys, and Federation entity fill -- without inventing a REST facade. This is a **Mesh
protocol** (not HTTP/REST Connectors). The loader stamps `@mongo__*` ops; Hive Gateway runs
`transport-mongo`. Stock Apollo Router does **not** execute them.

| Piece      | Detail                                       |
| ---------- | -------------------------------------------- |
| Loader     | `@omnigraph/mongo` (`loadMongoSubgraph`)     |
| Directives | `@mongo__findOne`, `@mongo__find`, CRUD, ... |
| Transport  | `@graphql-mesh/transport-mongo`              |
| Spec       | `https://specs.graphql-mesh.com/mongo/v0.1`  |
| Dual-run   | Hive Gateway only                            |
| Anchors    | `e2e/mongoose-users`                         |

## Generate from a Mongoose model

```ts
import { defineConfig } from '@graphql-mesh/compose-cli'
import { loadMongoSubgraph } from '@omnigraph/mongo'

export const composeConfig = defineConfig({
  subgraphs: [
    {
      sourceHandler: loadMongoSubgraph('Mongoose', {
        endpoint: 'mongodb://127.0.0.1:27017/mesh_users',
        models: [{ name: 'User', path: './src/models.js#User' }]
      })
    }
  ]
})
```

## Find by id and entity fill

Query `findUserById` uses `$args`; type-level `@mongo__findOne` uses `$this` for Federation:

```graphql
extend schema
  @link(
    url: "https://specs.graphql-mesh.com/mongo/v0.1"
    import: ["@mongo__findOne", "@mongo__find", "@mongo__insertOne"]
  )
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])

schema @transport(subgraph: "users", kind: "mongo", location: "mongodb://localhost:27017/test") {
  query: Query
}

type Query {
  findUserById(id: ObjectID!): User
    @mongo__findOne(
      collection: "user_users"
      query: """
      _id: $args.id
      """
      selection: """
      id: _id
      name: name
      age: age
      """
    )

  findUsers(filter: UserFilterInput, sort: [UserSort!], limit: Int = 100, skip: Int): [User!]!
    @mongo__find(
      collection: "user_users"
      query: "$args.filter"
      sort: "$args.sort"
      limit: "$args.limit"
      skip: "$args.skip"
      selection: """
      id: _id
      name: name
      age: age
      """
    )
}

type User
  @key(fields: "id")
  @mongo__findOne(
    collection: "user_users"
    query: """
    _id: $this.id
    """
    selection: """
    id: _id
    name: name
    age: age
    """
  ) {
  id: ObjectID!
  name: String
  age: Float
}
```

## Mutations

```graphql
type Mutation {
  insertOneUser(document: UserDocumentInput!): User
    @mongo__insertOne(
      collection: "user_users"
      set: "$args.document"
      selection: """
      id: _id
      name: name
      """
    )

  updateUserById(id: ObjectID!, update: UserUpdateInput!): User
    @mongo__updateOne(
      collection: "user_users"
      query: """
      _id: $args.id
      """
      set: "$args.update"
      selection: """
      id: _id
      name: name
      """
    )
}
```

## Edge cases

### Batch ByIds

`_id: $args.ids` on `@mongo__find` (loader snap) -- batch entity fill companion to singular
`findUserById`:

```graphql
type Query {
  findUsersByIds(ids: [ObjectID!]!, limit: Int = 100, sort: [UserSort!]): [User!]!
    @mongo__find(
      collection: "user_users"
      query: """
      _id: $args.ids
      """
      limit: "$args.limit"
      sort: "$args.sort"
      selection: """
      id: _id
      name: name
      """
    )
}
```

### Aggregate + connection

```graphql
type Query {
  aggregateUsers(filter: UserFilterInput, pipeline: JSON): [JSON!]!
    @mongo__aggregate(
      collection: "user_users"
      query: "$args.filter"
      pipeline: "$args.pipeline"
      selection: "$"
    )

  findUsersConnection(
    filter: UserFilterInput
    sort: [UserSort!]
    first: Int
    after: String
  ): UserConnection
    @mongo__connection(
      collection: "user_users"
      query: "$args.filter"
      sort: "$args.sort"
      first: "$args.first"
      after: "$args.after"
      selection: """
      nodes {
        id: _id
        name: name
      }
      """
    )
}
```

### ObjectId / Decimal128 / mixed JSON

Emitted schemas use GraphQL scalars such as `ObjectID`, `Decimal128`, and `JSON` for mixed fields --
transport options may list `objectIdFieldsByCollection`. See loader snap + `e2e/mongoose-users`.
