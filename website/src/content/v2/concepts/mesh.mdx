# Mesh

**Mesh** is a GraphQL Federation framework: it turns GraphQL and non-GraphQL sources into
**Federation-ready subgraphs** (and optionally a composed supergraph). Authors work in GraphQL SDL
with

<ConceptRef name="connectors">HTTP/REST Connectors</ConceptRef> and Mesh protocol directives.
Loaders can emit that SDL; humans and AI can hand-write it. Compose and the gateway treat both the
same.

| Layer                                    | Mesh role                                                  |
| ---------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------- |
| Loaders (`@omnigraph/*`)                 | Optional: introspect -> emit subgraph SDL                  |
| [Composition](/v2/compose)               | Subgraph / supergraph output, transforms, registry publish |
| Transports (`@graphql-mesh/transport-*`) | Execute directives at request time                         |
| Gateways                                 | [Hive Gateway](/v2/serve/hive-gateway) (full surface)      | [Apollo Router](/v2/serve/apollo-router) (Connect) |

Mesh is **not** the gateway binary itself, **not** a schema registry, and **not** Apollo Federation
spec ownership -- it produces and executes Federation-compatible SDL.

## Short example

```ts
// mesh.config.ts -- generate SQL catalog, compose with hand-written gRPC SDL
subgraphs: [
  { sourceHandler: loadSqlSubgraph('catalog', { endpoint: 'file:chinook.db' }) },
  { name: 'recommendations', schema: './recommendations.graphql' }
]
```

Emitted / authored SDL carries <DirectiveRef name="transport" />, protocol directives, and often

<DirectiveRef name="connect" /> / <DirectiveRef name="key" />. Walkthrough: [Music Store
Example](/v2/examples/music-store).
