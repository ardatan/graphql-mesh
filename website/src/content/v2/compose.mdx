# Compose

<ConceptRef name="composition">Composition</ConceptRef> via **Mesh Compose** turns subgraph
definitions into subgraph or supergraph GraphQL SDL -- the same path for loader emit and
hand-written files.

## Config shape (draft)

Typical `mesh.config.ts` ideas:

- `subgraphs` entries with a `sourceHandler` (loader) **or** a hand-written `schema` file / SDL
  string.
- Shared options: optional [transforms](/v2/transforms), additional type defs, output mode
  (`graphql` / binary formats as supported).

Generated and hand-written subgraphs share the same compose +

<ConceptRef name="schema-registry">schema registry</ConceptRef> path. Transforms are optional --
skip them when Hand-write or Generate-then-edit already owns the SDL.

## Hand-written SDL

```ts
{
  name: 'referenceResource',
  schema: './reference-resource.graphql',
}
```

Use this for join-only subgraphs, fully authored Connect SDL, and edited loader output.

## Registry publish

Publish composed **subgraph** SDL to Hive schema registry / GraphOS with the same CLI UX whether the
SDL came from a loader or a file. See [Schema registry](/v2/concepts/schema-registry).

Worked multi-subgraph config: [Music Store Example](/v2/examples/music-store) (catalog + reviews +
recommendations, then compose all).
