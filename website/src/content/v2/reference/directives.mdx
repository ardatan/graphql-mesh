# Directives reference

Apollo-style **directive reference** for Mesh subgraph SDL -- Connectors HTTP, Mesh protocol
directives, Federation join/`@key`, and `@link` / `@transport`. Modeled on
[Apollo Connectors directives](https://www.apollographql.com/docs/graphos/connectors/reference/directives).

<Callout type="info">
  **Draft stub.** TOC + short entries where args are already known from loaders / internal specs.
  Full per-arg catalog (every protocol family, examples, locations) is a completion-phase item --
  see the Mesh v2 docs plan.
</Callout>

Use this page when [reading generated SDL](/v2/guides/reading-generated-sdl) or
[hand-writing](/v2/paths/hand-write) subgraphs. Protocol family map: [Protocols](/v2/protocols).

## Connect HTTP

`@connect` / `@source`

Apollo Connectors–compatible HTTP mapping. Full arg tables live upstream:

- [Apollo Connectors directives](https://www.apollographql.com/docs/graphos/connectors/reference/directives)
- [JSONSelection / mapping](https://www.apollographql.com/docs/graphos/connectors/mapping)

Mesh notes:

- OpenAPI / JSON Schema / OData (and SOAP-as-Connect) loaders emit `@connect` / `@source`.
- Dual-run the same Connect SDL on [Hive Gateway](/v2/serve/hive-gateway) and
  [Apollo Router](/v2/serve/apollo-router).
- Common args you will see: `source`, `http` (`GET` / `POST` / …), `selection`, `entity`, `batch`.

```graphql
type Track @key(fields: "id", resolvable: false) {
  id: ID!
  reviews: [Review!]
    @connect(
      source: "reviews"
      http: { GET: "/reviews?trackId={$this.id}" }
      selection: """
      id
      rating
      """
    )
}
```

## Mesh core

`@transport`

Slim schema-level stamp: which Mesh transport Hive Gateway loads for this subgraph.

| Arg        | Meaning                                          |
| ---------- | ------------------------------------------------ |
| `subgraph` | Subgraph name                                    |
| `kind`     | Transport kind (`sql`, `mongo`, `protobuf`, …)   |
| `location` | Endpoint / connection string the transport opens |
| `headers`  | Optional header map                              |
| `options`  | Transport-specific options (dialect, etc.)       |

```graphql
schema @transport(subgraph: "catalog", kind: "sql", location: "file:chinook.db") {
  query: Query
}
```

`@transport` stays a Mesh schema directive for Hive Gateway `TransportEntry`. It is **not**
rewritten to `@join__directive` the way `@connect` / `@source` are.

## SQL

`@sql__query` / `@sql__mutation` / `@sql__relation`

Emitted by `@omnigraph/sql`; executed by `transport-sql`. Hive Gateway only (not stock Apollo
Router).

| Directive        | On              | Role                                             |
| ---------------- | --------------- | ------------------------------------------------ |
| `@sql__query`    | Query fields    | SELECT (`ROW` / `ROWS` / `CONNECTION` / `COUNT`) |
| `@sql__mutation` | Mutation fields | `INSERT` / `UPDATE` / `DELETE`                   |
| `@sql__relation` | Object fields   | FK / join navigation                             |

Shared args (shape):

| Arg         | Meaning                                              |
| ----------- | ---------------------------------------------------- |
| `subgraph`  | Owning subgraph (optional locally)                   |
| `table`     | SQL table name                                       |
| `kind`      | Query or mutation kind enum                          |
| `args`      | GraphQL args → WHERE / ORDER / LIMIT / column values |
| `selection` | Columns / payload → GraphQL fields                   |
| `entity`    | On ById query: Federation entity resolver            |

```graphql
type Query {
  track(id: ID!): Track
    @sql__query(
      table: "Track"
      kind: ROW
      args: """
      TrackId: $args.id
      """
      selection: """
      TrackId
      Name
      """
      entity: true
    )
}
```

Details expand with the SQL protocol chapter; Music Store Example stage 1 uses Chinook SQL generate.

<a id="mongo" />

## Mongo

`@mongo`

Single directive + `kind` discriminator (find / connection / CRUD / …). Hive Gateway only.

| Arg                                              | Meaning                                   |
| ------------------------------------------------ | ----------------------------------------- |
| `subgraph`                                       | Owning subgraph                           |
| `collection`                                     | Mongo collection                          |
| `kind`                                           | Operation kind                            |
| `where`                                          | Filter binder (`$args.where`, `$this`, …) |
| `orderBy` / `limit` / `skip` / `first` / `after` | List / connection binders                 |
| `set`                                            | Document values for writes                |
| `selection`                                      | Document → GraphQL fields                 |
| `pipeline`                                       | Aggregate stages (deferred depth)         |

```graphql
schema @transport(subgraph: "users", kind: "mongo", location: "mongodb://localhost:27017/test") {
  query: Query
}
```

## Protobuf / gRPC

`@protobuf__rpc`

Field or object directive for unary / server-streaming RPC. Hive Gateway only. Music Store Example
stage 3 hand-writes this family.

| Arg         | Meaning                                         |
| ----------- | ----------------------------------------------- |
| `subgraph`  | Owning subgraph                                 |
| `service`   | Protobuf service name                           |
| `method`    | RPC method                                      |
| `args`      | Compact GraphQL → protobuf request mapping      |
| `selection` | Compact protobuf → GraphQL field mapping        |
| `stream`    | Server-streaming when true                      |
| `entity`    | Wire `_entities` / `resolveReference` when true |

```graphql
type Query {
  recommendation(trackId: ID!): Recommendation!
    @protobuf__rpc(
      service: "Recommendations"
      method: "GetRecommendation"
      args: """
      1(string): $args.trackId
      """
      selection: """
      1(string): id
      2(string): trackId
      """
    )
}
```

`@link`: `https://specs.graphql-mesh.com/protobuf/v0.1` → `@protobuf__rpc`.

## Neo4j

Mesh uses **native** `@neo4j/graphql` directives (not a Mesh `@neo4j__*` dialect). Loader may
introspect or accept author SDL; transport filters by `subgraph:` vs `@transport(subgraph:)`. Full
catalog TBD -- see [Protocols](/v2/protocols).

<a id="federation" />

## Federation / join

`@key` / `@composeDirective`

| Directive           | Role                                                              |
| ------------------- | ----------------------------------------------------------------- |
| `@key`              | Entity key; often `resolvable: false` on join stubs               |
| `@composeDirective` | Which imported directives survive composition into the supergraph |

Join-only hand SDL (FHIR `Reference.resource`, Music Store entity stubs) typically combines `@key`
with Connect or protocol directives -- not Mesh `@resolveTo`.
