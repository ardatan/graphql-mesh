# Directives reference

Apollo-style **directive reference** for Mesh subgraph SDL --
[HTTP/REST Connectors](/v2/concepts/connectors) (`@connect` / `@source`), Mesh protocol directives,
Mesh join helpers (`@merge` / `@resolveTo`), Federation `@key`, and `@link` / `@transport`. Modeled
on
[Apollo's HTTP Connectors reference](https://www.apollographql.com/docs/graphos/connectors/reference/directives).

Use this page when [reading generated SDL](/v2/guides/reading-generated-sdl) or
[hand-writing](/v2/paths/hand-write) subgraphs. How `selection` / `args` binders work:
[Selection mapping](/v2/guides/selection-mapping). How we name a type, field, arg, or directive:
[Schema Coordinates](/v2/guides/schema-coordinates) (e.g. `Query.track(id:)`,
`@connect(selection:)`). Protocol family pages: [Protocols](/v2/protocols).

Each entry below includes how to **import** the directive with `@link` (Mesh Compose and loaders
stamp the same imports) plus a short real snippet from repo e2e / Music Store shape.

| Family               | Directives                                 | On this page                                           |
| -------------------- | ------------------------------------------ | ------------------------------------------------------ |

| Spec imports         | `@link`                                    | Spec URL table                                         |

## HTTP/REST Connectors

`@connect` / `@source`

HTTP/REST Connectors-compatible mapping (connect/v0.4). Full arg tables live upstream:

- [Apollo's HTTP Connectors reference](https://www.apollographql.com/docs/graphos/connectors/reference/directives)
- [JSONSelection / mapping](https://www.apollographql.com/docs/graphos/connectors/mapping) / Mesh:
  [Selection mapping](/v2/guides/selection-mapping)

**Import**

```graphql
extend schema
  @link(url: "https://specs.apollo.dev/link/v1.0")
  @link(url: "https://specs.apollo.dev/connect/v0.4", import: ["@connect", "@source"])
```

Mesh notes:

- OpenAPI / JSON Schema / OData (and SOAP-as-Connect) loaders emit `@connect` / `@source`.
- Dual-run the same Connect SDL on [Hive Gateway](/v2/serve/hive-gateway) and
  [Apollo Router](/v2/serve/apollo-router).
- Common args you will see: `source`, `http` (`GET` / `POST` / ...), `selection`, `entity`, `batch`.

```graphql
type Track @key(fields: "id", resolvable: false) {
  id: ID!
  reviews: [Review!]
    @connect(
      source: "reviews"
      http: { GET: "/reviews?trackId={$this.id}" }
      selection: """
      id
      rating
      """
    )
}
```

<a id="transport" />

## Mesh core

`@transport`

Slim schema-level stamp: which Mesh transport Hive Gateway loads for this subgraph.

**Import**

```graphql
extend schema @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])
```

Shared Mesh core also exports `@merge`, `@hoist`, `@source` (Mesh), `@resolveTo`, and pubsub helpers
under the same `core/v0.1` URL when needed -- import the names you use.

| Arg        | Meaning                                          |
| ---------- | ------------------------------------------------ |
| `subgraph` | Subgraph name                                    |
| `kind`     | Transport kind (`sql`, `mongo`, `protobuf`, ...) |
| `location` | Endpoint / connection string the transport opens |
| `headers`  | Optional header map                              |
| `options`  | Transport-specific options (dialect, etc.)       |

```graphql
schema @transport(subgraph: "catalog", kind: "sql", location: "file:chinook.db") {
  query: Query
}
```

`@transport` stays a Mesh schema directive for Hive Gateway `TransportEntry`. It is **not**
rewritten to `@join__directive` the way `@connect` / `@source` are.

<a id="merge" />

## Mesh `@merge`

`@merge`

Mesh type-merging helper (Hive Gateway). Marks how an entity (or a Query ById field) should be
looked up across subgraphs when Mesh is **not** using HTTP/REST Connectors / protocol `entity: true`
maps. Composition may still stamp `@merge` on non-Connect Mesh subgraphs that follow
[semantic ById conventions](/v2/compose#semantic-conventions); HTTP/REST Connectors subgraphs prefer
`entity: true` / type-level `$this` instead.

**Import**

```graphql
extend schema @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@merge"])
```

| Arg        | Meaning                                                    |
| ---------- | ---------------------------------------------------------- |
| `subgraph` | Owning subgraph name                                       |
| `keyField` | Entity key field on the type (e.g. `id`)                   |
| `keyArg`   | Query argument that carries that key (e.g. `id`)           |
| `argsExpr` | Optional richer arg expression when `keyArg` is not enough |

```graphql
type Query {
  product(id: ID!): Product @merge(subgraph: "Products", keyField: "id", keyArg: "id")
}

type Product @key(fields: "id") {
  id: ID!
  name: String
}
```

For new Federation-first work, prefer `@key` + HTTP/REST Connect or Mesh protocol entity resolution
([Entity resolution](/v2/concepts/federation#entity-resolution)). Use `@merge` when you need Mesh's
type-merging path on Hive Gateway (including legacy / non-Connect subgraphs).

<a id="resolveTo" />

## Mesh `@resolveTo`

`@resolveTo`

Mesh field-level **delegation / join** helper: resolve this field by calling another subgraph's
Query (or type) field, optionally with batched args. Still valid Mesh core; for new joins prefer
Federation `@key` stubs plus HTTP/REST Connect or protocol directives (see Music Store / FHIR).

**Import**

```graphql
extend schema @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@resolveTo"])
```

| Arg                    | Meaning                                                           |
| ---------------------- | ----------------------------------------------------------------- |
| `sourceName`           | Target subgraph name                                              |
| `sourceTypeName`       | Usually `Query` (or another type that owns the source field)      |
| `sourceFieldName`      | Field to call on that type                                        |
| `sourceArgs`           | Map of source args (`{ id: "{root.id}" }`, ...)                   |
| `requiredSelectionSet` | Parent fields needed before delegation                            |
| `pubsubTopic`          | Optional; subscription / webhook wiring without a subgraph target |

```graphql
type User {
  id: ID!
  repositories: [Repository]
    @resolveTo(
      sourceName: "A"
      sourceTypeName: "Query"
      sourceFieldName: "repositoriesByUserId"
      requiredSelectionSet: "{ id }"
      sourceArgs: { id: "{root.id}" }
    )
}
```

Deeper examples: [v1 Schema extensions](/v1/schema-extensions). Compose validates `sourceName` /
field / arg names at compose time.

<a id="sql" />

## SQL

`@sql`

Emitted by `@omnigraph/sql`; executed by `transport-sql`. Hive Gateway only (not stock Apollo
Router). One directive + `kind` discriminator covers query, mutation, and relation shapes (older
docs may show `@sql__*` aliases -- prefer `@sql`).

**Import**

```graphql
extend schema
  @link(url: "https://specs.graphql-mesh.com/sql/v0.1", import: ["@sql"])
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])
```

| `kind`                                  | Role                                  |
| --------------------------------------- | ------------------------------------- |
| `ROW` / `ROWS` / `CONNECTION` / `COUNT` | SELECT shapes                         |
| `INSERT` / `UPDATE` / `DELETE`          | Mutations                             |
| (field on object / type-level `@sql`)   | FK / join navigation and entity fills |

Shared args (shape):

| Arg         | Meaning                                          |
| ----------- | ------------------------------------------------ |
| `subgraph`  | Owning subgraph (optional locally)               |
| `table`     | SQL table name                                   |
| `kind`      | Query or mutation kind enum                      |
| `where`     | Equality / join predicates (`TrackId: $args.id`) |
| `args`      | Structured binders (filters, order, limit, ...)  |
| `selection` | Columns / payload -> GraphQL fields              |
| `entity`    | On ById query: Federation entity resolver        |

```graphql
type Query {
  track(id: ID!): Track
    @sql(
      table: "tracks"
      kind: ROW
      where: """
      TrackId: $args.id
      """
      selection: """
      id: TrackId
      name: Name
      albumId: AlbumId
      """
    )
}

type Track
  @key(fields: "id")
  @sql(
    table: "tracks"
    kind: ROW
    where: """
    TrackId: $this.id
    """
    selection: """
    id: TrackId
    name: Name
    albumId: AlbumId
    """
  ) {
  id: ID!
  name: String!
  albumId: Int
}
```

Binder vocabulary: [Selection mapping](/v2/guides/selection-mapping). Protocol:
[SQL](/v2/protocols/sql). Music Store Example stage 1 / `e2e/sqlite-chinook`.

<a id="mongo" />

## Mongo

`@mongo__*`

Op-specific directives (`@mongo__findOne`, `@mongo__find`, `@mongo__connection`, CRUD, ...). Hive
Gateway only.

**Import**

```graphql
extend schema
  @link(
    url: "https://specs.graphql-mesh.com/mongo/v0.1"
    import: [
      "@mongo__findOne"
      "@mongo__find"
      "@mongo__count"
      "@mongo__connection"
      "@mongo__insertOne"
      "@mongo__updateOne"
      "@mongo__deleteOne"
    ]
  )
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])
```

Import the ops you use (loaders stamp the full set). Typical args:

| Arg                                           | Meaning                                     |
| --------------------------------------------- | ------------------------------------------- |
| `subgraph`                                    | Owning subgraph                             |
| `collection`                                  | Mongo collection                            |
| `query` / `where`                             | Filter binder (`$args.where`, `$this`, ...) |
| `sort` / `limit` / `skip` / `first` / `after` | List / connection binders                   |
| `set`                                         | Document values for writes                  |
| `selection`                                   | Document -> GraphQL fields                  |
| `pipeline`                                    | Aggregate stages (deferred depth)           |

```graphql
schema @transport(subgraph: "users", kind: "mongo", location: "mongodb://localhost:27017/test") {
  query: Query
}

type Query {
  userById(id: ID!): User
    @mongo__findOne(
      collection: "users"
      query: """
      _id: $args.id
      """
      selection: """
      id: _id
      name
      email
      """
    )
}
```

Protocol: [Mongo](/v2/protocols/mongo). Binders: [Selection mapping](/v2/guides/selection-mapping).

<a id="protobuf" />

## Protobuf / gRPC

`@protobuf__rpc`

Field or object directive for unary / server-streaming RPC. Hive Gateway only. Music Store Example
stage 3 hand-writes this family.

**Import**

```graphql
extend schema
  @link(url: "https://specs.graphql-mesh.com/protobuf/v0.1", import: ["@protobuf__rpc"])
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])
```

| Arg         | Meaning                                         |
| ----------- | ----------------------------------------------- |
| `subgraph`  | Owning subgraph                                 |
| `service`   | Protobuf service name                           |
| `method`    | RPC method                                      |
| `args`      | Compact GraphQL -> protobuf request mapping     |
| `selection` | Compact protobuf -> GraphQL field mapping       |
| `stream`    | Server-streaming when true                      |
| `entity`    | Wire `_entities` / `resolveReference` when true |

```graphql
type Query {
  recommendation(trackId: ID!): Recommendation!
    @protobuf__rpc(
      service: "Recommendations"
      method: "GetRecommendation"
      args: """
      1(string): $args.trackId
      """
      selection: """
      1(string): id
      2(string): trackId
      """
    )
}
```

Compact mapping dialect: [Selection mapping](/v2/guides/selection-mapping). Protocol:
[Protobuf / gRPC](/v2/protocols/protobuf). Repo: `e2e/protobuf-http`.

<a id="thrift" />

## Thrift

`@thrift__rpc`

Binary Thrift path uses `@thrift__rpc`. TJSON over HTTP can emit HTTP/REST Connectors `@connect`
instead (dual-run when Connect-compatible). Do **not** brand binary Thrift as Connectors.

**Import**

```graphql
extend schema
  @link(url: "https://specs.graphql-mesh.com/thrift/v0.1", import: ["@thrift__rpc"])
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])
```

| Arg         | Meaning                               |
| ----------- | ------------------------------------- |
| `subgraph`  | Owning subgraph                       |
| `service`   | Thrift service name                   |
| `method`    | RPC method                            |
| `args`      | GraphQL -> Thrift request binders     |
| `selection` | Thrift response -> GraphQL fields     |
| `throws`    | Exception mapping (when emitted)      |
| `entity`    | Wire `_entities` / `resolveReference` |

Protocol: [Thrift](/v2/protocols/thrift).

<a id="neo4j" />

## Neo4j

Mesh uses **native** `@neo4j/graphql` directives (not a Mesh `@neo4j__*` dialect). Loader may
introspect or accept author SDL; transport filters by `subgraph:` vs `@transport(subgraph:)`.

**Import** (Mesh stamps)

```graphql
extend schema
  @link(url: "https://specs.graphql-mesh.com/neo4j/v0.1")
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])

schema @transport(subgraph: "graph", kind: "neo4j", location: "bolt://localhost:7687") {
  query: Query
}
```

Neo4j GraphQL directive definitions come from `@neo4j/graphql` itself; the Mesh `@link` marks the
subgraph for the neo4j transport. Protocol: [Neo4j](/v2/protocols/neo4j).

<a id="federation" />

## Federation / join

`@key` / `@composeDirective`

**Import**

```graphql
extend schema
  @link(url: "https://specs.apollo.dev/link/v1.0")
  @link(url: "https://specs.apollo.dev/federation/v2.6", import: ["@key", "@composeDirective"])
```

| Directive           | Role                                                              |
| ------------------- | ----------------------------------------------------------------- |
| `@key`              | Entity key; often `resolvable: false` on join stubs               |
| `@composeDirective` | Which imported directives survive composition into the supergraph |

Join-only hand SDL (FHIR `Reference.resource`, Music Store entity stubs) typically combines `@key`
with HTTP/REST Connect or Mesh protocol directives -- not Mesh <DirectiveRef name="resolveTo" />.
See also <DirectiveRef name="merge" /> for Mesh type-merging on Hive Gateway.

After importing Mesh / Connect directives, list each local name you need in the supergraph:

```graphql
extend schema
  @link(url: "https://specs.graphql-mesh.com/core/v0.1", import: ["@transport"])
  @composeDirective(name: "@transport")
```

Mesh Compose / loaders usually stamp `@composeDirective` for you.

<a id="link" />

## Spec imports

`@link`

Import directive definitions instead of pasting them. `@link` itself comes from the Apollo link
spec:

```graphql
extend schema @link(url: "https://specs.apollo.dev/link/v1.0")
```

| Family            | Typical URL                                    | Typical `import`                          |
| ----------------- | ---------------------------------------------- | ----------------------------------------- |
| HTTP/REST Connect | `https://specs.apollo.dev/connect/v0.4`        | `@connect`, `@source`                     |
| Federation        | `https://specs.apollo.dev/federation/v2.6`     | `@key`, `@composeDirective`, ...          |
| Mesh core         | `https://specs.graphql-mesh.com/core/v0.1`     | `@transport`, `@merge`, `@resolveTo`, ... |
| Mesh SQL          | `https://specs.graphql-mesh.com/sql/v0.1`      | `@sql`                                    |
| Mesh Mongo        | `https://specs.graphql-mesh.com/mongo/v0.1`    | `@mongo__findOne`, ...                    |
| Mesh protobuf     | `https://specs.graphql-mesh.com/protobuf/v0.1` | `@protobuf__rpc`                          |
| Mesh Thrift       | `https://specs.graphql-mesh.com/thrift/v0.1`   | `@thrift__rpc`                            |
| Mesh Neo4j        | `https://specs.graphql-mesh.com/neo4j/v0.1`    | (transport stamp; Neo4j natives separate) |

Mesh Compose injects matching definitions when you compose; loaders stamp the same imports on
generated subgraphs.
