# Apollo Router

**Apollo Router** is a **peer** <ConceptRef name="gateway">gateway</ConceptRef> to Hive Gateway in
the Mesh Serve Supergraph section (equal nav weight). Use it when your composed SDL is
**<ConceptRef name="connectors">HTTP/REST Connectors</ConceptRef>-compatible**
(<DirectiveRef name="connect" /> / <DirectiveRef name="source" /> on connect/v0.4-style emit).

## Honest limits

Stock Apollo Router executes **Connect** only. It does **not** run Mesh protocol transports:

| Surface                                                                                                                                                       | On Apollo Router?           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| <ProtocolRef name="http-rest" /> JSON Connect (OpenAPI / JSON Schema / OData when Connect-shaped)                                                             | Yes when Connect-compatible |
| SOAP-as-Connect (XML envelope)                                                                                                                                | No (expect Hive Gateway)    |
| <ProtocolRef name="sql" />, <ProtocolRef name="mongo" />, <ProtocolRef name="protobuf" />, <ProtocolRef name="thrift" /> binary, <ProtocolRef name="neo4j" /> | No                          |

For multi-protocol Music Store graphs, run the **full** supergraph on
[Hive Gateway](/v2/serve/hive-gateway); dual-run only the Connect slice here.

## Dual-run

Compose once to GraphQL SDL, then execute the same file on Hive Gateway and Apollo Router when the
schema stays on Connect:

```bash
mesh-compose -o supergraph.graphql
# Hive Gateway
hive-gateway supergraph
# Apollo Router (Connect-compatible SDL only)
./router --supergraph supergraph.graphql
```

### What dual-runs in the repo

| Example                             | Dual-run?    | Notes                                                               |
| ----------------------------------- | ------------ | ------------------------------------------------------------------- |
| `e2e/json-schema-fhir`              | Yes          | Connect emit + join-only hand SDL                                   |
| `e2e/openapi-entity-stubs`          | Yes          | `entity: true` / type-level `$this` Connect                         |
| Music Store after stage 2           | Reviews only | REST `@connect` slice; not SQL catalog or gRPC recommendations      |
| Music Store full (SQL+Connect+gRPC) | No           | Needs Hive Gateway for `@sql` / `@protobuf__rpc`                    |
| `e2e/thrift-calculator` TJSON       | Often        | `protocol: 'json'` emits `@connect`; binary `@thrift__rpc` does not |
| `e2e/soap-demo`                     | No           | SOAP envelope Connect is Hive-oriented                              |

Upstream Connect mapping:
[HTTP/REST Connectors reference](https://www.apollographql.com/docs/graphos/connectors/reference/directives).

<Callout type="info">
  Prefer [Hive Gateway](/v2/serve/hive-gateway) whenever any Mesh protocol directive is on the
  supergraph. Use Apollo Router to prove Connect compatibility, not as the only runtime for mixed
  graphs.
</Callout>
