# Hive Gateway

**Hive Gateway** is the preferred Mesh runtime. In Mesh docs it means the **JavaScript /
TypeScript** gateway. It executes the full Mesh transport surface (Connect, SQL, Mongo, Protobuf,
Thrift, Neo4j, …).

## When to use it

- Any Mesh-composed supergraph that uses non-Connect protocol directives.
- Connect-compatible supergraphs (alongside or instead of Apollo Router).
- Serving a Mesh subgraph as a Federation subgraph behind another router.

## In the Music Store Example

After all three stages, serve the **full** SQL + Connect + protobuf supergraph on Hive Gateway.
Dual-run only the Connect Reviews slice on [Apollo Router](/v2/serve/apollo-router). See
[Music Store Example](/v2/examples/music-store)#compose-all-three-then-serve.

## Related

Hive Gateway product docs live on the Hive site. Mesh docs focus on how Compose output and
transports plug in.
