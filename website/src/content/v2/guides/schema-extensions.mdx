# Schema extensions

In Mesh v2 the default way to "extend" across subgraphs is **Federation entities** and hand-written
join SDL -- not a gateway-only resolver dump. Compose already treats authored `.graphql` the same as
loader emit ([Hand-write](/v2/paths/hand-write), [Composition](/v2/compose)).

<Callout type="info">
  Prefer <DirectiveRef name="key" /> stubs +{' '}
  <ConceptRef name="connectors">HTTP/REST Connectors</ConceptRef> / protocol entity maps, or
  Federation `@lookup` / `@is` / `@internal` for one-object GraphQL entry fields. Type Merging{' '}
  <DirectiveRef name="merge" /> covers list/batch hops; <DirectiveRef name="resolveTo" /> is the SDL
  form of **additional resolvers** / field delegation -- see [Directives:
  @lookup](/v2/directives#lookup).
</Callout>

## Prefer entity joins

1. Own the hub type in one subgraph (Music Store catalog stamps `Track @key`).
2. Other subgraphs contribute fields with `resolvable: false` stubs or `entity: true` / protocol
   entity binders ([Entity resolution](/v2/concepts/federation#entity-resolution)).
3. Optional join-only file (no `Query`) for polymorphic references -- FHIR
   `reference-resource.graphql` is the supporting example ([FHIR](/v2/examples/fhir)).

{/* prettier-ignore */}
```graphql
# reviews.graphql -- extend Track owned by catalog
type Track @key(fields: "id", resolvable: false) {
  id: ID!
  reviews: [Review!]
    @connect(
      source: "reviews"
      http: { GET: "/reviews?trackId={$this.id}" }
      selection: """
        id
        rating
      """
    )
}
```

## When you still need extra SDL at Compose

Compose config can add `additionalTypeDefs` (often with `@resolveTo` as **additional resolvers**)
for gateway-local fields that are not owned by an upstream. Prefer that only when entity joins
cannot express the field. Keep those defs in a checked-in `.graphql` and list them beside other
subgraphs so registry publish stays the same UX.

{/* prettier-ignore */}
```graphql
# extensions.graphql -- gateway-local field delegation
extend schema
  @link(url: "https://specs.graphql-mesh.dev/core/v0.1", import: ["@resolveTo"])

extend type Book {
  # Delegate Book.authorId → Query.authorById on the "authors" subgraph
  author: Author
    @resolveTo(
      sourceName: "authors"
      sourceTypeName: "Query"
      sourceFieldName: "authorById"
      sourceArgs: { id: "{root.authorId}" }
      requiredSelectionSet: "{ authorId }"
    )
}
```

Wire the file as its own Compose subgraph entry (or merge into an existing hand SDL), compose, then
serve on [Hive Gateway](/v2/serve/hive-gateway). Full arg table:
[Directives: @resolveTo](/v2/directives#resolveTo). Stitching migrants:
[From Schema Stitching](/v2/guides/migration/from-stitching#from-delegatetoschema-to-resolveto).
