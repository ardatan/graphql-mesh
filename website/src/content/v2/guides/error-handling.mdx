# Error handling

Errors show up in three layers: **upstream HTTP / protocol** responses, **GraphQL field errors**
after transport mapping, and **gateway** masking / logging. Mesh Compose stamps the mapping; Hive
Gateway (or Apollo Router for Connect-only) executes it.

## HTTP/REST Connectors

Map upstream failure bodies with Connect `errors` on <DirectiveRef name="connect" /> when you need
typed GraphQL errors instead of a generic transport failure. Full arg tables:
[HTTP/REST Connectors reference](https://www.apollographql.com/docs/graphos/connectors/reference/directives)
(errors / `message` / `extensions`). Mesh summary: [Directives: @connect](/v2/directives#connect).

OpenAPI / JSON Schema loaders can also emit distinct response shapes per status where the upstream
document describes them -- see [HTTP / REST](/v2/protocols/http-rest).

## Mesh protocol transports

SQL / Mongo / protobuf / Thrift / Neo4j transports surface upstream failures as GraphQL errors with
transport-specific extensions. Prefer fixing binders (`where`, `args`, `selection`) when the error
is a mapping mistake -- [Reading generated SDL](/v2/guides/reading-generated-sdl) and
[Selection mapping](/v2/guides/selection-mapping).

## Gateway masking and logging

Redacting stack traces, setting `maskError`, and correlating logs with traces are **Hive Gateway**
features:

- [Logging and error handling](https://the-guild.dev/graphql/hive/docs/gateway/logging-and-error-handling)
- [Monitoring and tracing](/v2/guides/monitoring)

<Callout type="info">
  Auth failures (`UNAUTHORIZED_FIELD_OR_TYPE`, complete protection) are configured with the auth
  plugins -- see [Authentication](/v2/guides/auth). Rate-limit exceed messages come from
  <DirectiveRef name="rateLimit" /> / programmatic rules -- [Rate limiting](/v2/guides/rate-limit).
</Callout>
