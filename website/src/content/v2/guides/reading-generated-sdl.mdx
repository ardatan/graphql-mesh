# Reading generated SDL

Generated Mesh subgraphs are ordinary GraphQL SDL with directives. Before you edit or hand-write,
learn to recognize the important stamps. This page is a **reading guide**, not a full directive
catalog -- follow the links when you need the contract.

## What to look for

| Piece                         | Meaning                                                                                 | Dig deeper                                                                                                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@transport`                  | Which Mesh transport executes this subgraph at the gateway (kind, location, options).   | [Architecture](/v2/architecture) · [Protocols](/v2/protocols)                                                                                                |
| `@connect` / `@source`        | HTTP Connectors-style mapping (Apollo Connectors–compatible when dual-running Router).  | [Apollo Connectors directives](https://www.apollographql.com/docs/graphos/connectors/reference/directives) · [Serve: Apollo Router](/v2/serve/apollo-router) |
| Protocol directives           | `@sql` / `@sql__*`, `@mongo__*`, `@thrift__rpc`, `@protobuf__rpc`, Neo4j natives, …     | [Protocols overview](/v2/protocols) · [Music Store Example](/v2/examples/music-store) (SQL + Connect + gRPC stages)                                          |
| `@key`                        | Federation entity key; often with `resolvable: false` on join stubs.                    | [Music Store Example](/v2/examples/music-store) federation notes · [Architecture](/v2/architecture) patterns                                                 |
| `selection` / `args`          | How JSON (or rows) map into GraphQL fields and how field args become HTTP / RPC inputs. | [Apollo JSONSelection / mapping](https://www.apollographql.com/docs/graphos/connectors/mapping) · [Generate-then-edit](/v2/paths/generate-then-edit)         |
| `@link` / `@composeDirective` | Spec imports and which directives survive composition.                                  | [Compose](/v2/compose)                                                                                                                                       |

## Habits that help

1. Start from a **root field** you already queried, then follow its `@connect` / protocol directive.
2. Trace `$args` and `$this` in `selection` before renaming anything.
3. Treat emitted SDL as the contract you will either keep, edit, or rewrite by hand.
