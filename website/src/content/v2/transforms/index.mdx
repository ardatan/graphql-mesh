# Transform Subgraph

After you have subgraph SDL (from a [loader](/v2/paths/generate), a checked-in edit, or
[hand-written](/v2/paths/hand-write) GraphQL), you may still need to reshape names, drop noise, or
stamp Federation annotations before [Composition](/v2/compose). **Transform Subgraph** is that step
-- optional, per subgraph, two ways:

| Approach                              | What you change                                                              | When it fits                                                                                      |
| ------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| [Automatic](/v2/transforms/automatic) | `transforms: [...]` in Compose config (`createRenameTransform`, filter, ...) | Repeatable renames / filters / Federation stamps without touching the `.graphql`                  |
| [By hand](/v2/transforms/by-hand)     | Edit the subgraph `.graphql` yourself                                        | You want the public schema as committed SDL -- binders, keys, and fields updated in the same file |

Skip Transform Subgraph when Generate-then-edit or Hand-write already owns the public names you
want. Prefer **Automatic** for small, repeatable rewrites that should stay in config. Prefer **By
hand** when the edit is the source of truth -- worked SDL diffs live on that page.

Root-level (supergraph-wide) transforms are not the default story yet; reshape on the subgraph that
owns the names you want to change.
